# Request/reply experiment

Unpublished offline experiments for parent [CHECKLIST.md](../../CHECKLIST.md) -> `EP-X2.2`
and `EP-X2.3`.
Compare shared completion workers with assigned request lanes over one bounded channel
backend. A separate stateful path compares a shared synchronized table with private
key-owned partitions under identical per-key semantics. It is not the production
topology planner, a network service, a NUMA measurement
or a startup benchmark. See [DESIGN-NOTES.md](DESIGN-NOTES.md) for the contract.
