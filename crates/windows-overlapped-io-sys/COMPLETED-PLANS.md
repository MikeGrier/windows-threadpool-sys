Checklists whose planned work is complete. A checklist reappears in

finished. Individual milestones are archived in [COMPLETED-CHECKLIST.md](COMPLETED-CHECKLIST.md).

| [CHECKLIST.md](CHECKLIST.md) | 2026-08-17 | Overlapped-I/O foundation complete: endpoints/provenance, operation storage, raw IOCP and blocking backends, cancellation/rundown, submission seam, safe per-family adapters for file read/write and scatter/gather (`fs`) and sockets on both backends (`socket`), and a buffer-owning but `unsafe` raw-control-code `DeviceIoControl` seam (`device`). | [DESIGN-NOTES.md](DESIGN-NOTES.md) |
| [CHECKLIST.md](CHECKLIST.md) | 2026-08-22 | M10: `FILE_SKIP_COMPLETION_PORT_ON_SUCCESS` made usable end to end, closing an orphaned design decision. Adds `NotificationModes` and `UnassociatedEndpoint::set_notification_modes`, carries the mode through association so the submission seam can answer "will a packet arrive", gives `Operation` a synchronous byte-count cell for the out-parameter the adapters previously passed as null, and (breaking) changes every buffer-owning adapter to return a two-state `Started` outcome so a synchronous no-packet completion is reported rather than rejected. | [DESIGN-NOTES.md](DESIGN-NOTES.md) |
| [CHECKLIST.md](CHECKLIST.md) | 2026-08-22 | M11: caller-supplied owned buffers, so no adapter forces a copy or an allocation. Adds the `IoBuf`/`IoBufMut` stable-address traits and makes every IOCP adapter generic over the caller's buffer -- `Vec<u8>`, `Box<[u8]>`, `Arc<[u8]>`, `&'static [u8]`, `PageBuffers`, or a caller's own pooled type -- handing the same value back on completion. The blocking adapters take plain slices instead, which is cheaper and sound because they block for the whole operation. Breaking, taken while the crate has no adopters. | [DESIGN-NOTES.md](DESIGN-NOTES.md) |
| [CHECKLIST.md](CHECKLIST.md) | 2026-08-22 | M12: closed the two gaps M10 and M11 left as prose notes at the foot of the checklist. Adds `IoBuf`/`IoBufMut` for `&'static mut [u8]` -- the one reference type that is exclusive, and so the one that is a legal read destination -- which M11 had deferred on the forbidden "no consumer yet" grounds. Adds `AssociatedSocket::set_notification_modes` behind an IFS-handle capability probe (`getsockopt(SOL_SOCKET, SO_PROTOCOL_INFOW)`, refusing with `Unsupported`), making socket skip-on-success reachable for the first time, with `classify_socket` made mode-aware and `WSARecv`/`WSASend`'s byte-count out-parameter wired up in the same change so the two can never disagree. | [DESIGN-NOTES.md](DESIGN-NOTES.md) |
